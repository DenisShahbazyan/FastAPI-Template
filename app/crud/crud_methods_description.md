# Описание методов CRUD базового класса

## 📖 Обзор методов

Базовый CRUD класс предоставляет **53 метода** для работы с данными, разделенных на логические группы:

---

## 🔍 **GET методы - Получение данных**

### Простое получение
- **`get()`** - Получает один объект по простым условиям (поле=значение)
- **`get_or_404()`** - То же что `get()`, но возвращает 404 ошибку если объект не найден
- **`get_multi()`** - Получает список объектов с фильтрацией, сортировкой и пагинацией
- **`get_multi_or_404()`** - То же что `get_multi()`, но возвращает 404 если список пустой

### Сложные условия
- **`get_by_condition()`** - Получает один объект по сложным SQL условиям (AND, OR, LIKE и т.д.)
- **`get_by_condition_or_404()`** - То же что `get_by_condition()`, но с 404 ошибкой
- **`get_multi_by_condition()`** - Получает список объектов по сложным условиям
- **`get_multi_by_condition_or_404()`** - То же что `get_multi_by_condition()`, но с 404 ошибкой

### Специальные методы получения
- **`get_with_deleted()`** - Получает объект включая мягко удаленные записи

---

## 📊 **Утилитарные методы - Подсчет и проверки**

- **`count()`** - Подсчитывает количество объектов по простым условиям
- **`count_by_condition()`** - Подсчитывает количество объектов по сложным условиям
- **`exists()`** - Проверяет существование объекта по простым условиям
- **`exists_by_condition()`** - Проверяет существование объекта по сложным условиям

---

## ➕ **CREATE методы - Создание данных**

### Базовое создание
- **`create()`** - Создает один объект из Pydantic модели
- **`bulk_create()`** - Создает несколько объектов за один раз

### Умное создание
- **`get_or_create()`** - Получает объект или создает если не существует (по простым условиям)
- **`get_or_create_with_pydantic()`** - То же что `get_or_create()`, но с Pydantic моделью
- **`get_or_create_by_condition()`** - Получает или создает объект по сложным условиям

### Универсальные методы
- **`upsert()`** - Создает новый объект или обновляет существующий (INSERT или UPDATE)
- **`bulk_upsert()`** - Массовый upsert для списка объектов

---

## ✏️ **UPDATE методы - Обновление данных**

### Обновление по объекту
- **`update()`** - Обновляет объект по экземпляру объекта с Pydantic моделью
- **`update_or_404()`** - Находит и обновляет объект или возвращает 404 ошибку

### Массовое обновление по условиям
- **`update_by_fields()`** - Обновляет объекты по простым условиям (dict данные)
- **`update_by_fields_or_404()`** - То же что `update_by_fields()`, но с 404 ошибкой
- **`update_by_condition()`** - Обновляет объекты по сложным SQL условиям
- **`update_by_condition_or_404()`** - То же что `update_by_condition()`, но с 404 ошибкой

### Обновление с Pydantic
- **`update_with_pydantic_by_fields()`** - Обновляет объекты по простым условиям с Pydantic моделью
- **`update_with_pydantic_by_fields_or_404()`** - То же но с 404 ошибкой

### Массовые операции обновления
- **`bulk_update_by_ids()`** - Обновляет объекты по списку ID
- **`bulk_update_by_field_values()`** - Обновляет объекты по списку значений определенного поля
- **`bulk_update_all_by_fields()`** - Обновляет все подходящие объекты порциями (для больших таблиц)

---

## 🗑️ **DELETE методы - Удаление данных**

### Физическое удаление
- **`delete()`** - Удаляет объект по экземпляру объекта
- **`delete_by_fields()`** - Удаляет объекты по простым условиям
- **`delete_by_fields_or_404()`** - То же что `delete_by_fields()`, но с 404 ошибкой
- **`delete_by_condition()`** - Удаляет объекты по сложным условиям
- **`delete_by_condition_or_404()`** - То же что `delete_by_condition()`, но с 404 ошибкой

### Массовое физическое удаление
- **`bulk_delete_by_ids()`** - Удаляет объекты по списку ID
- **`bulk_delete_by_field_values()`** - Удаляет объекты по списку значений определенного поля
- **`bulk_delete_all_by_fields()`** - Удаляет все подходящие объекты порциями
- **`bulk_delete_all_by_condition()`** - Удаляет все подходящие объекты по условиям порциями

### Мягкое удаление (Soft Delete)
- **`soft_delete()`** - Мягко удаляет объект (устанавливает флаг удаления)
- **`soft_delete_by_fields()`** - Мягко удаляет объекты по простым условиям
- **`soft_delete_by_condition()`** - Мягко удаляет объекты по сложным условиям
- **`restore()`** - Восстанавливает мягко удаленный объект

---

## 🎯 **Принципы работы методов**

### **Логика именования:**
- **Без суффикса** - базовая функциональность
- **`_or_404`** - то же самое + HTTPException при отсутствии данных
- **`_by_fields`** - фильтрация по простым условиям (поле=значение)
- **`_by_condition`** - фильтрация по сложным SQL условиям
- **`_with_pydantic`** - работа с Pydantic моделями
- **`bulk_`** - массовые операции
- **`soft_`** - мягкие операции (без физического удаления)

### **Возвращаемые значения:**
- **Объекты** - `get*`, `create*`, `update`, `upsert`, `restore`
- **Списки** - `get_multi*`, `bulk_create`, `bulk_upsert`
- **Числа** - `count*`, `update_by_*`, `delete_by_*` (количество затронутых записей)
- **Булевы** - `exists*`
- **Кортежи** - `get_or_create*`, `upsert*` (объект, был_ли_создан)

### **Управление транзакциями:**
- Все методы используют `flush()` вместо `commit()`
- Управление транзакциями остается на усмотрение вызывающего кода
- Автоматический rollback при race conditions в методах создания

### **Безопасность:**
- Обязательная валидация входных параметров
- Защита от случайного удаления/обновления всей таблицы
- Проверка существования полей в модели
- Обработка race conditions

---

## 💡 **Рекомендации по использованию**

### **Для простых операций:**
```python
# Используйте базовые методы
user = await crud.get(session, id=1)
users = await crud.get_multi(session, is_active=True)
```

### **Для сложных запросов:**
```python
# Используйте condition методы
users = await crud.get_multi_by_condition(
    session,
    and_(User.age >= 18, User.city.in_(["Moscow", "SPB"]))
)
```

### **Для API endpoints:**
```python
# Используйте _or_404 методы
user = await crud.get_or_404(session, id=user_id)
posts = await crud.get_multi_or_404(session, user_id=user_id)
```

### **Для массовых операций:**
```python
# Используйте bulk_ методы
await crud.bulk_update_by_ids(session, user_ids, {"is_active": False})
```

### **Для безопасного удаления:**
```python
# Используйте soft_delete вместо delete
await crud.soft_delete(session, user)
```
